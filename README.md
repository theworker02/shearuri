# shearuri

Shear filesystem uri paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/shearuri/

## Install / run

```bash
git clone https://github.com/theworker02/shearuri.git
cd shearuri
node src/cli.js
node --test
```
